# Overload Ware Labs Ai (Owl Ai) Internship
Internship Tasks:

Task 1: Understanding of AI/ML Researcher role.


Explaining the key responsibilities, required tools, and the importance of an AI/ML Researcher in today’s tech industry. Including a Q&A section at the end to demonstrate basic understanding of the field.

Task 2: Research on Large Language Models (LLMs) 


Exploring popular Large Language Models such as ChatGPT, Gemini, DeepSeek, Claude, and others. Discuss how they work, their applications, limitations, and future potential.

Task 3: EDA Project.

Performed an Exploratory Data Analysis on any publicly available dataset from Kaggle. Identifying key data patterns, visualize relationships, and summarized findings in a clear and concise report.
